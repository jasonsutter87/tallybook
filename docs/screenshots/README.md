# Screenshots

The main README links to these files. Until they exist, those images show as
broken links.

| File | What to capture | Suggested screen |
|---|---|---|
| `hero.png` | The overall look | Home dashboard, full window, light mode |
| `home.png` | Money at a glance | Home: the hero card, to-do strip and stats |
| `review.png` | Categorizing | Review with one row expanded (category picker open) |
| `invoice.png` | A finished invoice | An issued or paid invoice view |
| `bills.png` | What you owe | Bills list with the summary cards |
| `reports.png` | Reports | Profit & loss, year to date |
| `taxes.png` | Tax center | Taxes → Schedule C (worksheet + mapping) or Overview |
| `dark-mode.png` | Dark theme | Any screen in dark mode (Home works well) |

Tips:

- Use the Northwind Studio sample book so no real numbers appear. The app
  no longer offers it on the welcome screen; create it from the dev server
  (see [DEVELOPMENT.md](../DEVELOPMENT.md)).
- About 1440×900 looks good. Keep the same window size for every shot.
- On macOS, <kbd>⌘</kbd><kbd>⇧</kbd><kbd>4</kbd> then <kbd>Space</kbd>
  captures one window. Hold <kbd>⌥</kbd> while clicking to leave out the
  shadow.
- PNGs are fine; keep each under about 1 MB if you can.
